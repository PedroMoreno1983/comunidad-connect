# Reglas de comparación del carro de supermercado

1. El producto elegido en la primera tienda es la referencia. Su marca, nombre, atributos, presentación, cantidad y precio permanecen en el carro original.
2. Otra tienda puede ofrecer la misma marca o una marca equivalente. La marca propia de una cadena nunca se presenta como el mismo producto de otra cadena.
3. Una alternativa automática debe coincidir en tipo de producto, atributos declarados (por ejemplo, entera frente a descremada, sabor, azúcar y sal) y cantidad del envase. Las medidas se normalizan: 1 L equivale a 1000 ml y 1 kg a 1000 g. Cuando el nombre no declara medida, se exige la misma unidad de venta explícita.
4. Entre alternativas válidas se prefiere la misma marca comercial; después, el menor total para la cantidad solicitada. El nombre, foto, precio y marca concretos siguen visibles antes del traslado al supermercado.
5. Si falta una alternativa verificable o un identificador de carro, la canasta de esa tienda es incompleta. Su subtotal se presenta como parcial y no se ofrece como ahorro ni como carro completo.
6. Las listas pegadas o subidas se resuelven en el catálogo del supermercado elegido. Las líneas que no coinciden quedan pendientes para buscar o quitar expresamente. Mientras haya pendientes no se habilita el traslado del carro.

Estas reglas son intencionalmente conservadoras: el catálogo no tiene un identificador universal fiable compartido por todas las cadenas. La selección final y el precio definitivo deben confirmarse en la tienda.
